# Otobüs Yan Koltuk Savunma Savaşı

> Durak yaklaşır. Kapı açılır. Bir vatandaş gözünü senin yanındaki boşluğa diker.
> Bu bir ulaşım meselesi değildir. Bu bir sınır meselesidir.

Bu depo, Türkiye Cumhuriyeti sınırları içindeki belediye otobüslerinde, yan koltuğun boş kalmasını **resmî olmayan ama son derece resmî** bir savunma hattıyla hesaplar. Yazılım çalışır. Savaş kazanılmaz. Savaş ertelenir. Bir sonraki durakta yeniden başlar.

Patates içermez. Simit içermez. Asansör içermez. Sadece koltuk, çanta ve utancı içerir.

## Neden var

Çünkü yan koltuk boşken insan iki kişilik nefes alır. Biri kendisi için, biri çantası için. Bu nefes anayasal değildir. Yine de herkes bilir.

Savunma araçları sınırlıdır:

1. Çantayı koltuğa yatırmak (pasif işgal)
2. Kulaklık takmak (diplomatik sağırlık)
3. Camdan bakmak (coğrafi ret)
4. Sahte telefon konuşması açmak (sözlü mayın)
5. “Burası dolu, arkadaşım iniyor” demek (hayali müttefik)

Yazılım bu araçları puanlar, durak sayısını çarpar, kalabalık katsayısını ekler ve bir **savunma kararnamesi** basar.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Çünkü yan koltuk da bağımsız olmak ister, başaramaz.

```bash
python yan_koltuk.py
```

Kendi cephe hattınız için:

```bash
python yan_koltuk.py --canta orta --kulaklik evet --camdan-bak evet --sahte-telefon 18 --hayali-arkadas evet --durak 4 --kalabalik 7 --saat 18:10
```

## Örnek karname

```
DOSYA NO : YK-20261003-1740
KARAR    : SAVUNMA TUTUNDU, AMA UTANÇ TUTANAĞA GEÇTİ
PUAN     : 73/100
EMİR     : Çantayı indir. Kulaklığı çıkarma. Göz teması kurma.
```

Puan yüksekse koltuk bir süre daha senindir. Puan düşükse yazılım seni ihbar etmez; sadece içinden bir durak adı fısıldar.
